Teacher guide

Put the first demo on the projector. Give each team the student page and let them choose a project. Pupils can use any tool they know. The screenshot guides use Scratch.

Download the three teacher demos

Open each file in Scratch with File → Load from your computer. Reopen a demo to return it to its starting screen.

MinuteWhat to do
00–07Try all three ideas. Invite a pupil to click one thing in each demo. Ask who each project helps.
07–15Choose and open a starter. Form teams of 2–3. One pupil drives, one follows the screenshots and a third can test.
15–25Make one click work. Model dragging the two blocks once. Pause while each team gets a speech bubble to appear.
25–42Build the prototype. Swap who has the keyboard. Make the first useful response, test it, then add the second.
42–54Swap and improve. Let a visiting team use the project. Fix one part they struggled with.
54–60Save and show. Each team saves its file and demos one working feature to a neighbouring team.

Coach prompt. “Show me the last thing that worked. What should happen on the next click?” A team with one tested response is ready to share.
